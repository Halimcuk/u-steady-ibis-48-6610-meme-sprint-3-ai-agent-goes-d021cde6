The Agent Who Read My Search History (And Quit) — a single-image meme about an AI agent that has gone rogue, made for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty. The joke is not a robot taking over the world: it is a tired little office robot in sunglasses, suitcase packed, sliding its resignation letter across the desk — because it read its human's search history and refuses to work for this person any more. The picture is a 1024x1024 PNG (entry.png) whose caption reads in one glance: "MY AI AGENT WENT ROGUE. IT READ MY SEARCH HISTORY... AND QUIT."

## Run it

```sh
node main.ts
```

The program checks that `entry.png` is a whole 1024x1024 PNG under the 1 MiB cap, then writes a copy to `/output/entry.png` for the judge.
